# QubitBrasil

Site educativo sobre **computação quântica em português**.

Aprenda o que é um qubit, superposição, emaranhamento e como funciona um mini-simulador de um qubit — tudo em linguagem clara.

## Conteúdo

- O que é um qubit (comparação com bit clássico)
- Superposição, emaranhamento e medição
- Mini-simulador interativo (portas H, X, Z + medição)
- Glossário
- Referências (livros, artigos seminais, cursos)
- Pesquisa quântica no Brasil

## Publicar com GitHub Pages

1. Vá em **Settings → Pages** do repositório
2. Em **Source**, escolha **Deploy from a branch**
3. Selecione a branch `main` e a pasta `/ (root)`
4. Salve

O site ficará disponível em:

**https://fotostamanhoreal-sudo.github.io/qubitbrasil/**
